## Tested, not just demoed

**8,562 automated tests** across fifty-eight repositories: 5,113 in the sixteen featured repositories (554 agentic-ai + 116 agent platform + 232 integration platform + 161 agent labs + 58 learning lab + 201 Fabric + 237 FinOps + 593 model risk + 685 maturity + 344 AI SOC + 520 agent identity security + 180 AI SOC assurance + 666 agentic data layer + 108 agent auth security + 175 langchain-langgraph-langsmith + 283 agentic-playwright (148 Playwright + 135 pytest), counted with pytest, and Playwright Test where present, in each repository's own environment) and 3,449 in the forty-two learning and pattern repositories (counts in the table above). All pass except four that are skipped on purpose. Two are maturity tests that are skipped on purpose: one needs a reference text that is never committed, the other compares a live scan of the sibling checkouts and only runs when asked. The other two check a deploy workflow in the food-ingredients project that is planned and not written yet. Every push runs lint, tests and eval gates in GitHub Actions, plus Terraform validation, offline plan tests, tflint and checkov on the infrastructure. Every repository also pins its GitHub Actions to commit SHAs, scans its full git history with gitleaks, runs CodeQL and gets weekly Dependabot updates; secret scanning with push protection, Dependabot security updates, private vulnerability reporting and a `main` ruleset (no force-push or deletion, CI required on pull requests) are switched on.
