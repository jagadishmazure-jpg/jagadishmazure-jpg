## Tested, not just demoed

**13,454 automated tests** across one hundred and two repositories: seventeen in the ([a-z-]+) featured repositories (554 agentic-ai + 116 agent platform + 232 integration platform + 161 agent labs + 58 learning lab + 201 Fabric + 237 FinOps + 593 model risk + 685 maturity + 388 AI SOC + 520 agent identity security + 180 AI SOC assurance + 666 agentic data layer + 108 agent auth security + 175 langchain-langgraph-langsmith + 283 agentic-playwright (148 Playwright + 135 pytest) + 152 AKS agent platform, counted with pytest, and Playwright Test where present, in each repository's own environment) and 8,145 in the eighty-five learning and pattern repositories (counts in the table above). All pass except four that are skipped on purpose, plus four real-Redis/Postgres integration tests in the system-design repo that skip offline and run against service containers in its CI, and one tokenizer comparison test in the capacity-planning repo that skips without the optional tiktoken encoding and runs in its CI. Two are maturity tests that are skipped on purpose: one needs a reference text that is never committed, the other compares a live scan of the sibling checkouts and only runs when asked. The other two check a deploy workflow in the food-ingredients project that is planned and not written yet. Every push runs lint, tests and eval gates in GitHub Actions, plus Terraform validation, offline plan tests, tflint and checkov on the infrastructure. Every repository also pins its GitHub Actions to commit SHAs, scans its full git history with gitleaks, runs CodeQL and gets weekly Dependabot updates; secret scanning with push protection, Dependabot security updates, private vulnerability reporting and a `main` ruleset (no force-push or deletion, CI required on pull requests) are switched on.
